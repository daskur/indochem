# IPLA DEVELOPMENT PLAN

## Phase 1: Foundation
1. Create folders and documentation.
2. Create schema and seed data.
3. Configure PDO and shared helpers.
4. Create reusable layout and responsive styles.
5. Add authentication and the home page.
6. Build processes, equipment and chemicals.

## Phase 2: Learning Features
1. Industrial calculators.
2. Laboratory safety.
3. Flow diagrams.
4. Video tutorials.
5. Quiz and practice.
6. Glossary and global search.

## Phase 3: Advanced Features
1. SIWES logbooks and reports.
2. Profiles and progress history.
3. Bookmarks and certificates.
4. News and notifications.
5. Complete admin CRUD panels.
6. PDF export and advanced search.

## Working Method
Every feature begins by reading the project context and progress files. Implement only the current module, verify it, update progress, changelog and context, then stop when the module task is complete.
